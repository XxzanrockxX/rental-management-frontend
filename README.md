# Rental Management - Frontend

Frontend application for a vehicle rental management system focused on customer and rental contract management.

## Technologies

- React
- JavaScript
- CSS
- HTML

## Planned Features

- User login and authentication.
- Home page with year selection.
- Year and period navigation.
- Monthly rental contract organization.
- Contract search by date, customer name, ID number, and rented vehicle.
- Integration with the backend REST API.
- Weather information through the Open-Meteo API.

Installation instructions and environment variables will be documented during development.
